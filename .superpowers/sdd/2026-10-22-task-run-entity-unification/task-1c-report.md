No Action-level Run owner is introduced. The identity map distinguishes source physical ID, typed public ID, target Run and optional child identity.

The deterministic field map covers all declared fields for candidate, review, selection, supplement, embedded execution and execution-alias source families, plus frozen source relationship/count/index metadata. The target and retirement artifacts contain no row bodies or trajectories. The exact duplicate selection body remains omitted because current `action_payloads(selection_references=True)` already removes physical `branch_json`.
