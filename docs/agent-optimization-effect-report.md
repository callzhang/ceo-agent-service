# Agent 优化效果报告

报告日期：2026-10-25（America/Los_Angeles）。本报告复用已完成的验收、固定案例及生产回读，不新增模型评测或业务任务重放。生产结论截至10月25日20:49 PDT的已保存回读，不代表持续实时监控。

## 结论

本轮达成了三个主要结果：减少不必要的初始指令；让当前Codex CLI的结构化输出、续会话及Settings输入追溯具备可核对证据；移除普通文档写入的自动全文读回与内容比对，让任务验收回到业务目标与真实执行结果。

**已证明输入更少、固定场景行为通过、修改已加载到生产；尚未证明整体更快、费用更低或生产重复写入率下降。** 按用户最后确认的范围，本轮已收尾。原“必须等到特定格式的自然写入样本”条件已取消，不能改写为通过。

## 1. 输入减少：有可比数字

| 对照范围 | 优化前 | 优化后 | 已验证效果 |
| --- | ---: | ---: | --- |
| 原六个冷启动固定场景，事实、配置及模型一致；Developer+Task字符合计 | 215,702 | 158,018 | 减少57,684字符，26.74% |
| Meeting同案例完整输入与精简输入 | 对应完整输入 | 每次减少17,415字符 | 约减少42%；9组对照、18次原生运行 |
| 原生输出格式说明按需读取，同一说明段 | 11,909字符 | 373字符 | 初始段减少11,536字符，96.9%；完整契约仍可通过CLI读取 |

以上是不同阶段、不同范围的对照，**不能相加成为总节省**。按需读取可能在首轮补回完整Skill或schema，因此不能从初始字符数推断完整会话token、缓存费用或耗时。较早删除重复Pydantic schema曾减少13,116字符，属于历史阶段数据，不叠加到上述最终按需结果。

来源：[按任务指令验收](task-scoped-prompts-validation.md)、[Meeting精简对照](meeting-managed-skill-scope-validation.md)、[最终对账第6、13节](agent-optimization-final-acceptance.md)。

## 2. 业务行为：固定案例有效，结论限定样本

- **Meeting：**同一组9个案例中，基线7/9通过业务检查，精简候选9/9通过；两组共18次运行均产生合法结构。基线两处问题为无依据分配Alex执行工作、在群消息中暗示有人事话题。结果支持这组案例没有因精简退化，且修正了观察到的问题；样本不足以证明普遍质量提升。
- **日历、邮件、文档和工作跟踪：**当前Codex CLI复核原六个场景及续跑，共7个阶段、9次实际原生调用。最终各阶段达到标准：跨午夜与时区、真实重叠、已处理邮件、文档数字/日期冲突、复用已有工作事项和Audit反馈。跨午夜首轮只部分通过，补足边界事实后通过；工作跟踪首轮夹具范围不严被排除，修正夹具后仅重跑该例。不能写成“9/9首轮业务通过”。
- **成果复用：**自然定时任务417176保留51/51来源工件，两次反馈进入新修订，最终有provider发送成功回执。这证明该任务的工件复用与修订闭环，不代表所有任务都不会重复工作。

来源：[最终对账第4、10节](agent-optimization-final-acceptance.md)、[通用定时续跑核查](scheduled-continuation-closure-verification.md)。本报告没有重跑这些已有效案例。

## 4. 文档写入：消除不必要的核验链路

历史基线中，Consumer396024的62次文档写入有52次“已写入但核验失败”；11组重复写入产生24次额外相同内容覆盖。这是一个具体长任务的基线，不是全系统日均故障率。

最终按用户决定，PR327采用已有DWS原生create/update，移除自动全文读回、readback工件和格式/内容比较。成功时保留真实provider写入回执、文档身份和提交SHA；写入失败或提交状态未知仍报错。JSONML输入解析、revision检查及版本保存保留。日报、周报、OKR周报Skill同步取消强制写后全文比对，Audit继续审核任务目标。

因此可以确认：**经该共用工具正常写入后，服务不再发起额外正文读回，也不再因这一自动比较产生失败。** 不能据此声称生产“24次额外覆盖已经降为0”或所有原因的重复写入都已消失；未进行修复后同条件生产数量对照。

验证为4项先失败后通过的回归、112项受影响测试和30项发布器测试；独立源码/集成审查无阻塞。另30项集成角色边界检查与112项重叠，不重复计数。一项主线已有数据库夹具测试仍查询已删除列，单独记录而未改标通过。

来源：[文档写入验证](document-write-recovery-validation.md)、[PR327](https://github.com/callzhang/ceo-agent-service/pull/327)。
