# Unselected exact AI Minutes reader, A2

This local change adds a request-scoped AI Minutes provider adapter to the A1 source reader. No caller selects it and no Store, DDL, provider authorization, production checkout, or live source is changed. Without an injected DWS reader, a provider locator remains `reader_unavailable`. Other source kinds remain unimplemented. This is one provider branch of Unit A, not completion of the provenance redesign.

`minutes_provider_locator` accepts the original canonical body transiently and retains only the existing exact UUID from `source_ref` and the presence of `meeting`, `todos`, `transcript_excerpts`, and `meeting_summary`. It accepts only the original producer's canonical JSON and matching meeting UUID. The `#todos-sha256=` suffix is preserved as the existing source reference; it identifies the queued action set and is not treated as a provider or whole-body history version. Locator metadata contains no body, Todo payload, transcript paragraph, or summary.

The reader calls `list_minutes_page(scope="all", limit=50, cursor=...)` without a date window, exhausts pagination, and requires one unambiguous exact UUID record. It then reads Todo actions; transcript and summary endpoints are read only when those components existed in the original canonical body. The existing producer formatter and excerpt/summary helpers reconstruct the complete body. The shared A1 path checks UTF-8 byte length, SHA-256, and the eight-field identity key, then applies requested source-ref and quote checks. A changed current provider body yields `version_mismatch`; missing, duplicate, incomplete, or contradictory provider data cannot stand in for the historical body. Typed DWS unreadability becomes `source_incomplete`; unexpected implementation errors remain visible.

The unwindowed lookup may scan all AI Minutes pages per distinct binding and has no guessed total-page limit. This favors exact identity over a date guess, but large histories can make a first request expensive. The request map fetches one complete body per exact binding and refuses a same-key conflicting locator. A1 native reads retain their original behavior.
