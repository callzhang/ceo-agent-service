## 已证实原因

- 判读 key 只摘要页面文本，实际模型输入还包括主机、控件及 Developer 指令；不同输入可能命中相同已完成 runtime。
- 相同跳过结果重读会保留原动作回执，而 worker 原来只记录摘要，当前页面没有自己的持久 owner。
- Attempt 详情按 action identity 读取当前回执及全部步骤，因此历史 Attempt 也可能显示另一运行的页面。

原生 trajectory 已原地核对：相关判读返回 action_required，并读到 unsubscribe/continue 控件；没有 DOM 证据证明弹窗处理错误，不据此修改控件逻辑。
