# Attempt Detail 阅读与操作界面

Attempt 详情页以一次处理结果为中心：触发内容、审计说明和生成回复各只展示一次。原始 Codex 草稿不再作为第二个“回复”区块出现，避免与“生成回复”混淆。

右侧的“需要你的判断”“内部反馈/建议修改”和“对方反馈”属于同一条处理侧栏，使用统一卡片边界和间距。它们是不同的操作或记录，不能因为文本长短而隐藏。

普通文本摘要采用按实际溢出显示的控制项：

- 内容在当前行数内完整显示时，不显示“展开详情”。
- 内容被截断时，才显示“展开详情”；展开后可“收起”。
- 容器宽度或摘要内容变化时，会重新判断是否需要该控制项。

这条规则由共享 `SummaryText` 组件执行，覆盖 Attempt、Task、Feedback、Attention 和业务详情中的文本摘要；表格行的结构化“展开详情”仍仅在它确实包含额外字段时使用。
