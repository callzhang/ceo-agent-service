# Email 阅读与模型训练

## 邮件分类

列表保留全部、待确认、已处理和退订筛选，以及页码和每页数量。打开邮件后，宽屏为列表/原文双栏；窄屏为全宽阅读。返回列表保留当前页和选中邮件。上一封/下一封只在本页已加载邮件内切换。

分类控件在正文上方。待确认邮件可以直接确认已有建议，不必先修改类别；已处理邮件也可以重新选择并保存。成功后重新读取服务端数据，失败保留当前选择。重要状态来自邮箱观察，未知状态不显示为“未标星”。

原文只使用保存的正文，不生成摘要，不执行邮件 HTML、脚本或远程资源。历史已平铺或截断的内容不能恢复成原邮件排版。引用与附件元数据单独展示，不读取附件内容。

处理记录按动作展示结果、时间及关联 Attempt。退订任务结束不代表退订成功：界面使用回执 outcome，缺结果时显示未知。退订地址先显示可用性；只有明确显示地址时才调用独立读取接口。不可用地址不阻止查看 Attempt。完整日志、回执标识和 ActionPlan 在技术详情中。

## 模型训练

总览显示当前影子/主模式、真实候选的分数与延迟。历史 registry 的 active 登记不代表当前线上模型。晋升仍由服务端门槛控制，切换保留确认和版本冲突保护。

“新建训练”选择来源、类别和模型家族。样本预览按与训练相同的冻结文件夹快照筛选规则，对邮件身份去重；不创建训练任务或写入反馈。计数包括训练与验证数据，不等于每个模型最终拟合的行数，也不保证全部模型都满足训练条件。提交时重新校验快照和各模型条件。

有效选择没有匹配样本时显示 0 并禁止提交；读取错误则显示错误和重试。改变选择会取消旧预览。提交期间锁定选择，防止显示内容与提交内容不一致。任务提交不等于训练完成，界面不构造百分比或成功状态。

“晋升设置”单独编辑门槛；版本详情分为效果、数据与参数、技术信息，保留完整模型名和评测证据。趋势只连接相同家族、协议、测试集与类别集合的相邻有效数据；没有测量不画作零分。

## 本次尚未补齐的能力

- 重要标记目前只读。现有外部动作路径支持设置，但没有完整的取消标记与 UI 回读接口；本次没有新增绕过 Audit 的直接邮箱写入。
- 总览不把重叠来源的记录数相加充当全局可训练数。精确去重计数在具体训练选择的预览中查看。
- 训练进度只显示现有接口实际提供的状态和运行标识；缺少持久化的逐模型阶段时不推断成功或失败。

这些是当前实现差距，不是对已批准设计的重新定义。发布前需明确接纳差距或继续补齐。
