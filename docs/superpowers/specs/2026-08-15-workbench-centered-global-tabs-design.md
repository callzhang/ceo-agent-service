# Workbench 顶部 Tab 居中与统一样式设计

## 目标

顶部全局导航在桌面可用宽度内视觉居中，六个 Tab 使用一致的尺寸、间距、字体、边框、悬停态和选中态，并与 Workbench 现有绿色主色保持一致。

## 设计

- 保留 `GlobalNav` 的现有语义、链接顺序和横向滚动容器。
- 导航内容宽度小于视口时，用 Flex 居中；宽度超过视口时保持内容自身宽度并允许从左到右横向滚动。
- 所有 Tab 复用 `.global-nav-item`，设置统一最小宽度并居中文本；短标签不再显得大小不一，长标签仍可自然扩展。
- 选中态使用现有 `--accent`，悬停态使用 `--accent-soft`，不引入新颜色或组件库。

## 验收

- 桌面端导航项整体中心与页头中心一致。
- 六个 Tab 高度、最小宽度、圆角、字体和对齐一致。
- Agent 选中态与页面绿色品牌色一致。
- 窄屏仍能横向滚动，不截断链接。
- 现有导航可访问性和目标地址测试继续通过。
