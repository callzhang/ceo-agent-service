# Private business Skill migration

Derek authorized continuing the established split: the service stays open source;
company business packages, source material and policy tests move to a separate
private repository. Preserve Native execution. This is a source/location migration,
not a new approval policy or a rollout of the unpublished OA judgment candidate.

Use the current installed packages as the private baseline, including support files
and executable bits. Record a per-file SHA manifest and verify source stability.
Keep company policy fixtures and their tests private. Preserve the unpublished OA
candidate separately without applying it to the baseline. Native Git credentials
remain the only repository authentication mechanism.

The public service retains generic baseline templates, the existing runtime and
installer, and synthetic/contract tests. Remove company OA packages and internal
source links from its current release tree. Remove those assets from the old
explicit release file list; do not change verification, rollback, Audit rules,
permissions or execution contracts. Generic baseline template publication is not
an update channel for company packages. Keep optional external Skill identifiers
where needed for existing installations; identifiers are not policy bodies.

Current installed same-name packages must not be overwritten. Verify private URL
search on production. Verify actual Install and repeat Install in an isolated
console with a fresh database and installed directory, using the service's real
routes/reader/installer and native account credentials. Verify complete files,
exact commit, pending binding and a real child-process loader receipt. Do not
start business workers or send/replay business actions in acceptance.

The alternatives already discussed were publishing company packages with the
service, using the personal mixed Skill repository, or a dedicated private source.
The first violates the requested boundary; the second mixes authoring ownership.
Use the dedicated private source. History rewriting is deliberately excluded:
removing current files cannot undo earlier public disclosures. Record that limit.
