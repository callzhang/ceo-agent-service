# Service Update Navigation Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. User approved direct implementation, tests and release; no further design gate.

**Goal:** Detect GitHub upstream updates, show a global update button, review all-commit notes and formally deploy the displayed version after draining active work.
**Architecture:** Reuse RepositoryUpgradeService snapshots and native app.deploy. Add release notes keyed by immutable local/target SHAs; single commit uses original text, multiple commits call the existing native Codex runner and validate <=500chars. React control reads status without waiting for the deploy mutex and polls through restart.
**Tech Stack:** Python/FastAPI, native Git/Codex CLI, SQLite existing service_state, React/TypeScript/Vitest.

Spec: docs/superpowers/specs/2026-10-20-service-update-design.md
