Its update predicate includes `record_type` and canonical public `legacy_key`; it does not change `session_id`, public ID, or `created_at`. It neither infers membership from meeting runs nor adds a source pointer FK, so the approved 700 metadata members and 698 distinct source pointers remain representable. It removes the already unused summary/FTS/vector parameters and all persistent FTS writes. The only application call to this upsert is `_index_meeting_codex_session`; that helper passed no retired parameters, and the patch removes only its unused `embedding_client` parameter and corresponding call argument.
