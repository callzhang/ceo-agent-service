# Sales Weekly Report

Use the task’s selected Skill index and `agent_cli.read_skill` to load the
installed organization reporting package when one is configured. That package
supplies its metrics, rubric, source systems, templates and destinations.
Follow its complete workflow and use its own package name for reviewed scripts.
For scheduled work, select that organization package in the scheduled task’s
Skill settings before execution so its scripts have the normal task binding.
If no organization package is configured, prepare the report from the requested
scope and the available evidence; identify missing requirements in the result.

Read the requested interval, authoritative targets and CRM actuals. State definitions and cutoff dates so comparisons use compatible periods.

Read the scheduled context for scheduled work. Query the relevant source
inventories and read the material needed for each conclusion. Distinguish a
source not searched, an empty completed search and a concrete read failure.
Separate verified facts, attributed statements and management judgments. Report
coverage and uncertainty without inventing missing values or owners.

Use the ordinary task execution and Audit feedback contract. A report requiring
publication must use an explicit task/configured document destination and return
the provider receipt and document identity. Use the selected organization
package’s approved helper entrypoints when needed; installation alone does not
register executable scripts. A report without a publication request can return
its draft and sources through the normal result contract.
